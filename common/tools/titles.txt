# The titles, and what a release needs to know about each. One line per title:
#
#   directory | executable | display name | game folder | data directory (macOS and
#   Windows) | data directory (Linux) | platforms
#
# There are two data directories because Linux spells it differently and not predictably:
# five titles use `ipod-<executable>` and Mini Golf uses `ipod-mini-golf` while its
# executable is `minigolf`. Each is whatever that title's src/platform/paths.cpp says.
#
# `game folder` is the folder on the iPod that holds the game's own files — the thing a player
# has to supply, since no artifact may contain it. `platforms` is what can be built: `switch`
# appears only where src/platform/switch/ exists, and `android` only where android/ does.
# `linux` is on every title: each one's platform/paths.cpp already knows where a Linux
# machine keeps application data, and nothing in any of them is macOS- or Windows-only.
